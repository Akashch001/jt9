# JT9 Detailing Website

A high-performance, mobile-first website for JT9 Detailing built with modern web technologies, cinematic scroll choreography, and responsive design.

## Features

- **Cinematic Scroll Experience:** Purpose-driven scroll reveals and subtle depth using native `IntersectionObserver` and GPU-composited CSS transitions.
- **Mobile-First Design:** Fully responsive layout optimized for smartphones, tablets, and desktops with dynamic viewport (`100dvh`) support and touch feedback.
- **Interactive Before/After Slider:** Comparison slider for paint correction results with touch and keyboard navigation.
- **Multi-Step Quote Estimator:** Fast, intuitive vehicle selection and service estimation workflow.
- **High Performance & Accessibility:** Lightweight implementation, fast Core Web Vitals, and full support for `prefers-reduced-motion`.
- **Search Engine Optimization:** Semantic HTML5 structure, structured metadata, and crawlable content.

## Tech Stack

- **HTML5 & Vanilla CSS:** Modern CSS custom properties, fluid typography, and glassmorphic UI elements.
- **Vanilla JavaScript:** High-performance interactions and scroll observers with zero framework overhead.
- **Vite:** Fast development server and optimized production build tool.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
